## 보는 방법

- GitHub에서는 아래 개별 이미지 링크를 눌러 원본을 확인할 수 있습니다.
- 전체 파일을 내려받아 압축을 풀고 `index.html`을 브라우저로 열면 60장을 한 번에 탐색할 수 있습니다. 이미지 클릭은 원본 열기, `PNG 저장`은 개별 다운로드입니다.
- 전신과 프로필의 번호는 각 컬렉션 안에서의 순서입니다. 피드백 시 `전신 07`, `프로필 24`처럼 구분해 주세요.
- 갤러리는 HTML과 CSS로 구성되어 있으며 외부 폰트, 라이브러리, 네트워크 연결, 빌드 과정이 필요하지 않습니다. 모든 링크는 상대경로입니다.
